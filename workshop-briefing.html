Getting Started with Git: Objectives

Workshop Objectives

This hands-on workshop is designed to equip students with industry-standard version control skills. By the end of this session, participants will be able to:

  • Master essential command-line tools to track, stage, commit, and sync code modifications (git status, git add, git commit, git push, git pull).
  • Understand Git local architecture and file transitions (Working Directory, Staging Area, and Local Repository).
  • Navigate collaborative workflows on GitHub by managing branches and opening Pull Requests (PRs).
  • Publish a live contribution to a shared repository using HTML/CSS.
Time Slot Phase Description & Student Activity
10:00 AM – 10:15 AM Welcome & Setup Participant check-in, Wi-Fi connection, software verification.
10:15 AM – 10:55 AM Interactive Concepts Facilitator presents visual slides covering Version Control, Git vs. GitHub, 3 local areas, and repository initialization (git init vs git clone).
10:55 AM – 11:15 AM Live Demo Facilitator demonstrates the complete workflow live on screen (Fork ➔ Clone ➔ Branch ➔ Edit ➔ Commit ➔ Push ➔ Pull Request).
11:15 AM – 12:00 PM Student Hands-On Students work on laptops: create a branch (git switch -c), customize an HTML card, stage/commit changes, and push to GitHub (git push).
12:00 PM – 12:20 PM Live PR Merge Showcase Students submit Pull Requests. Facilitator merges PRs live on projector screen, rendering cards in real-time on the Student Gallery wall.
12:20 PM – 12:30 PM Wrap-Up & Q&A Best practices, resolving merge conflicts, open Q&A, and group photo.
