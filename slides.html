Why Git? 02 / 18

The "Chaos" of File Management

Ever collaborated on a group project and ended up with files like this?

  • ❌ project_final.zip
  • ❌ project_final_v2_EDITED.zip
  • ❌ project_final_v3_for_real_THIS_ONE.zip

Git solves this completely: no extra ZIP files, no lost code, total history tracking.

Core Concepts 03 / 18

The 3 Local Areas of Git

  • 1 Working Directory: Your actual files on your laptop.
  • 2 Staging Area (Index): The launchpad where you stage changes with git add.
  • 3 Local Repository: Saved snapshots committed with git commit.

Step 1: Setup 04 / 18

Configure Your Identity

Open your Terminal (Mac/Linux) or Git Bash (Windows) and check your settings:

git --version
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
Step 2: Clone 05 / 18

Download the Workshop Code

Clone the repository to create your local copy on your laptop:

git clone https://github.com/your-username/git-ready.git
cd git-ready

Tip: Open index.html in your browser to see the live Wall of Fame!

Step 3: Compass 06 / 18

Your Compass: git status

When in doubt, always run git status. It tells you what branch you're on and what files changed.

git status
# On branch main
# Your branch is up to date with 'origin/main'.
Step 4: Branching 07 / 18

Create Your Feature Branch

Never code directly on main! Create a dedicated branch for your student profile:

git checkout -b student/your-github-username

The -b flag creates a new branch and switches to it in one command.

Hands-On Task 08 / 18

Create Your Profile JSON Card

Inside your code editor (VS Code), create a new file under data/students/your-username.json:

{

Step 5: Stage 09 / 18

Stage Your Changes: git add

Tell Git to stage your new file for the next commit:

git add data/students/your-username.json
# Or stage all untracked changes:
git add .

Run git status to verify your file turned green (staged)!

Step 6: Snapshot 10 / 18

Commit Your Snapshot: git commit

Save your changes into Git history with a descriptive commit message:

git commit -m "feat: add Alex Rivera profile card"

Best Practice: Use present-tense imperative messages (e.g., "feat: add...", "fix: resolve...").

Step 7: Upload 11 / 18

Push to GitHub: git push

Upload your branch from your local laptop to GitHub:

git push origin student/your-github-username

Your branch is now live on GitHub!

Step 8: Collaborate 12 / 18

Open a Pull Request (PR)

  • 1 Go to the repository URL on GitHub in your browser.
  • 2 You will see a banner: "Compare & pull request". Click it!
  • 3 Add a title: feat: Add [Your Name] profile card and click Create pull request.

Sync Everyone's Cards: git pull

Pro Tip 15 / 18

Handling Merge Conflicts Calmly

Conflicts happen when two people edit the exact same line in the same file. Don't panic!

<<<<<<< HEAD (Your changes)
"role": "Frontend Developer"
=======
"role": "Fullstack Engineer"
>>>>>>> main (Incoming changes)

Solution: Pick the correct version, delete the conflict markers (<<<, ===, >>>), stage and commit!

Best Practices 16 / 18

Golden Rules of Git

  • ✨ Commit Often: Make small, logical commits instead of massive weekly dumps.
  • 🌿 Use Branches: Keep main deployable at all times.
  • 💬 Clear Messages: Write commit messages that explain why, not just what.
  • 🔄 Pull Before Push: Keep your branch synced with upstream changes.
Real-World Utility 17 / 18

Why Git Powers Modern Tech

  • 🌐 Global Open Source: Linux, React, Python are built by thousands via Git.
  • ⚡ CI/CD & Automation: Pushing code automatically builds, tests, and deploys apps.
  • 🛡️ Time Machine: Revert any bug instantly without breaking production.
