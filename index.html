Interactive Git Command Cheat Sheet

Essential commands you will use during today's workshop:

1. Clone Repository

git clone <repo-url>

Downloads a full copy of the remote repository to your laptop.

2. Create Feature Branch

git checkout -b student/your-name

Creates a brand new isolated branch so your work doesn't affect main.

3. Stage & Commit Changes

git add .
git commit -m "feat: add my student profile"

Stages changed files and saves a snapshot into Git history.

4. Push to GitHub & Sync

git push origin student/your-name
git pull origin main

Pushes your branch to GitHub for PR review, and pulls merged changes from others.
